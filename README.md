# Limpieza-y-An-lisis-de-Datos-con-Tidyr-y-Stringr---Caso-NeoCar
Práctica avanzada de limpieza y estructuración de datos desordenados (data cleaning) usando tidyr y stringr en R. Incluye normalización de textos, imputación de valores faltantes, reestructuración tabular (pivots), uniones multiclave y análisis cruzados con clientes y comisiones.
